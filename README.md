# Notepad

A modern note-taking application built with React, Vite, and Tailwind CSS. Features AI-powered assistance via Puter.ai.

## Features

- Create, edit, and delete notes
- Folder organization with drag-and-drop
- Rich text editor with formatting
- AI assistant integration (Puter.ai)
- Pin, archive, and restore notes
- Search and filter functionality
- Dark mode support
- Export notes to HTML

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 4
- TypeScript
- Puter.js (AI assistant)
